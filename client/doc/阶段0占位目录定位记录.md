# 阶段 0 占位目录定位记录

## 现象

阶段 0 目录生成和后续查看过程中，当前目录状态中出现了占位项：

- `新目录项`
- `项目需求理解`

其中 `新目录项` 的描述为 `请编辑描述`，`项目需求理解` 当前描述也为 `请编辑描述`。

## 定位结论

`新目录项` / `请编辑描述` 不是 AI 目录生成提示中的输出模板，而是前端目录编辑页手动新增目录时的默认值。

代码位置：

- `src/features/technical-plan/pages/OutlineEditPage.tsx`
- `addRootItem()` 默认创建 `{ title: '新目录项', description: '请编辑描述' }`
- `addChildItem()` 默认创建 `{ title: '新目录项', description: '请编辑描述' }`

当前 SQLite 中占位项也符合这个特征。

## 产品判断

这不是阶段 1 响应矩阵要直接解决的问题，但会影响阶段 2 大纲覆盖和阶段 4 正文生成。

后续应增加校验：

- 大纲进入正文生成前，不允许存在 `新目录项`。
- 大纲进入正文生成前，不允许存在 `请编辑描述`。
- 如果用户确实手动新增目录，需要先编辑标题和描述。
- 响应矩阵覆盖检查时，应把未编辑占位项标为高风险。

## 对阶段 0 验收的影响

阶段 0 的运行基线仍然成立：真实招标文件解析和目录生成已经成功。

但生成结果不能直接视为可交付大纲；验收时需要把占位项作为已发现问题记录，并在阶段 2 修复。
